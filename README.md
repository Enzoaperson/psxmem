# PSXMem 2.0
A rewrite of my original Playstation Memory Card Viewer, this time with extra features!

## New Features

### Better designed

Works more like an actual Unix program using actual dash arguments instead of just letters for switches. The actual parsing of commands has also been improved.

### More information

Save data's country code and size is now displayed along side the name, id and icon!

### More supported Memory Card Formats

Alongside Raw and PSP memory card files being supported, the .GME format is now supported to!

### Cores

Cores allow for certain save data to display more then the bare minimum of an icon, name and size. Currently I only have a basic Ridge Racer core setup (I've gotten really into Ridge Racer), although I plan to add more in the future!
